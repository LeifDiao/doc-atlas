Turn a stack of docs
into one dashboard. 一摞文档,
梳成一张面板。

"Summarize this PDF" just hands you more to read. Doc Atlas does the opposite: it asks what you want out of the documents, merges across files, surfaces the numbers and conclusions that clash, and renders one offline, self-contained HTML briefing — a one-sentence verdict on top, a big logic diagram as the star, and every number one click from the page it came from. 「帮我总结这个 PDF」给你的只是更多要读的字。Doc Atlas 反过来:先问你想从这批文档里得到什么,再跨文件合并、把互相打架的数字和结论显式挑出来,炼成一张离线、自包含的 HTML 简报——首屏一句话定论,逻辑大图当主角,每个数字点一下都能回到它出自的那一页。

Why Doc Atlas凭什么用它

Read the panel, not the pile.看面板,不必再翻那一摞。

A pile of files to decide on, too slow to read one by one. Doc Atlas doesn't hand you yet another summary — it pulls them into one panel where you grab the main thread in ten seconds, click in for detail, and trace any number back to its page, so you call it faster and with more confidence.一摞文件要决策,一篇篇啃太慢。Doc Atlas 不是再多给你一篇摘要,而是把它们收成一张能十秒抓主线、要细节再点开、每个数字都能回溯的面板——让你更快也更稳地拍板。

Any format in, not a number lost什么格式都能进,数字一个不丢

Drop in PDF / Word / PPT / Excel / HTML / EPUB / Markdown and it all flattens into one readable layer. PDF tables are re-extracted by row and column so the numeric columns survive; scanned files fall back to OCR — a lot of figures that "aren't in the original" are really just table columns a plain conversion dropped. Page numbers and images are kept too, so every number can point back to the page it came from.PDF / Word / PPT / Excel / HTML / EPUB / Markdown 直接扔进去,统一拍平成一层可读内容。PDF 表格按行列重抽、保住数值列,扫描件自动走 OCR——很多「看似原文没写」的数,其实是普通转换把表格列丢了。页码和图片也都留着,后面每个数字才能指回原文哪一页。

It fuses them into one, not a list of summaries是把它们捏成一张,不是一篇篇罗列

Multiple files are de-duplicated first, then woven into one unified outline — not a summary per file. When numbers, dates, or conclusions across files don't match, the conflict is laid out plainly for you to judge instead of silently picking one — exactly where multi-file work trips you up is where this earns its keep.多个文件先去重,再织成一张统一目录,而不是逐个文件给你一段摘要。当几份文件的数字、日期、结论对不上,冲突会被明明白白摆出来让你自己判断,而不是悄悄替你选一个——多文件最容易被坑的地方,恰恰也是它最值钱的地方。

See at a glance what drives what, where money flows一眼看清谁影响谁、钱怎么流

After a full read, the core causality and relationships across the documents become one full-width diagram you can click to zoom — not a footnote in the corner. What drives what, where the money flows, where risk piles up — one picture makes it clear; charts come in wherever numbers should do the talking. It's your fastest way to a whole-picture judgment.通读之后,整套文档的核心因果和关系会被画成一张整行大图,点击放大,而不是塞在角落的脚注。谁影响谁、钱怎么流、风险卡在哪,一张图就交代清楚;该用数字说话的地方再配上图表。这是你最快建立全局判断的入口。

Every number traces back — so you can trust the panel每个数字都能回溯,你才敢信这张面板

Every claim carries a badge back to file + page — one click to check it. A health-check report tells you how much was covered, compressed, and still to verify — and its numbers are audited against the parsed sources, not self-reported. Before rendering, an adversarial pass refutes the high-risk numbers against the original, and every checked claim lands in a per-claim table in the appendix — so reading the panel is enough, no going back to the PDFs.每条结论都挂着回到「文件 + 页码」的角标,点一下就能核对。一张体检表告诉你覆盖了多少、压了多少、还有多少待核实——而且这些数字会和解析出的原文对账,不是自说自话。渲染前再派一道对抗式核查回原件证伪,每条核过的结论都进附录的明细表——让你看面板就够,不必再回去翻 PDF。

Send it to anyone — it opens intact, never falls apart发给谁都原样打开,不会散架

The output is a single dashboard.html with all content and images packed inside: send it to a colleague or drop it into an archive and they double-click to see exactly what you saw — no missing images, no broken layout. Behind it, the AI only produces a structured model.json and a fixed renderer draws everything, so every output comes out consistent — not great today and a mess tomorrow.产出是单个 dashboard.html,所有内容和图片都打包在里面:发给同事、丢进存档,对方双击就能原样看到,不会缺图、不会跑版。背后是 AI 只产出结构化的 model.json、由固定渲染器统一出图,所以每次产出都稳定一致,不会今天好看明天乱。

Asks your language and your goal, answers in a briefing先问语言和目标,答案排成一份简报

Before it starts, it asks which language you want and what you want out of the documents — the goal drives what counts as important and what makes the front screen. The layout is a warm rice-paper briefing: a one-sentence verdict on top, numbered sections down a single spine, chapters folded until you want them, sources tucked into a quiet appendix — ten seconds for the main thread, details on demand.开工前先问你要哪种语言、想从文档里得到什么——重要性怎么分、首屏放什么数字,都对着这个目标来。版面是暖米纸的简报式排法:首屏一句话定论,编号分区一条主线读下来,章节折叠着等你点开,来源沉在页尾附录——十秒抓主线,细节再展开。

How it works它怎么跑

The AI writes structure. The renderer draws.AI 写结构,渲染器作图。

01
Scan扫描
Scan the folder, then confirm language, files, and what you want out of them — in one prompt.扫描文件夹,一次确认语言、纳入哪些文档、你想从中得到什么。
02
Normalize归一化
Each file becomes a Markdown layer — page numbers and images preserved.每个文件转成 Markdown 中间层——页码和图片都留着。
03
Consolidate & check合并 + 核查
Merge across files, surface conflicts, then an adversarial fact-check against the source.跨文件合并、挑出冲突,再对抗式回原件核查。
04
Render渲染
model.json → one self-checked dashboard.html that opens offline.model.json → 一个经自检、离线可开的 dashboard.html。
scan → normalize (any format → Markdown) → consolidate (dedupe · conflicts) → fact-check → model.json → deterministic render → self-check → dashboard.html 扫描 → 归一化(任意格式 → Markdown) → 合并(去重 · 冲突) → 事实核查 → model.json → 确定性渲染 → 自检 → dashboard.html

On first use it installs the parsing dependencies (markitdown + PyMuPDF, ~290 MB) into an isolated .venv — only after you consent. Decline and nothing is installed.首次使用会把解析依赖(markitdown + PyMuPDF,约 290MB)装进隔离的 .venv——征得你同意才装。不同意则不装任何东西。
